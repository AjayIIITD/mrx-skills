# MRX Skills

OpenCode skills for YouTube channel auditing and Instagram account auditing.

## Skills

### youtube-channel-audit
Deep YouTube channel audit & growth strategy — analyzes channels, videos, thumbnails, titles, retention, SEO, monetization, and competitors. Use this skill whenever a user asks to audit, review, analyze, or get feedback on their YouTube channel or any video.

### gym-plus-plus
Systems-level health and human performance coach — root-cause analysis, integrated training/nutrition/recovery/skin/lifestyle optimization, phased implementation, and adherence-focused planning for users with multiple interconnected health and fitness goals.

### skill-creator
Create new skills, modify and improve existing skills, and measure skill performance.

### instagram-account-audit
Instagram account audit & growth score — analyzes Instagram profiles across key growth factors like profile optimization, content quality, reels strategy, engagement quality, consistency, branding, and monetization readiness.

## Installation

### OpenCode
Add to your `opencode.jsonc`:

```jsonc
{
  "skills": {
    "youtube-channel-audit": {
      "name": "youtube-channel-audit",
      "description": "Deep YouTube channel audit & growth strategy",
      "path": "/path/to/skills/youtube-channel-audit"
    },
    "skill-creator": {
      "name": "skill-creator",
      "description": "Create and iterate on skills",
      "path": "/path/to/skills/skill-creator"
    },
    "instagram-account-audit": {
      "name": "instagram-account-audit",
      "description": "Instagram account audit & growth score",
      "path": "/path/to/skills/instagram-account-audit"
    }
  }
}
```
